## What it tests

_Tie it back to the validation brief: which assumption does this prototype put in front of a user?_

Sales rep can selet select, write and schedule email. Snooze follow up removes it from today's list of to do.

## Context injected (no placeholders)

- **Real user quotes on screen:** “It's faster to keep my deals in a spreadsheet than to fight the CRM's eight required fields.” / “I never know where the thing I need lives. Every screen looks like a settings page.”
- **Domain metrics on screen:** 18% Weekly active adoption across licensed seats. / 8 Required fields to log a single deal update. / 11 min Avg. task time for "update a deal" vs. 2-min target.
